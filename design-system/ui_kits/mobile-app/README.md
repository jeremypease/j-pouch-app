# Mobile App UI kit

Interactive click-through recreation of the J-Pouch companion app: onboarding → dashboard (Home) → log entry → insights → profile/settings. Built from `components/` primitives (Button, Card, StatCard, Input, Select, Checkbox, Switch, Tabs, TabBar, Badge, Icon) — no re-implemented primitives.

Open `index.html`. Files: `Onboarding.jsx`, `Home.jsx`, `LogEntry.jsx`, `Insights.jsx`, `Profile.jsx`, composed by the inline `App` in `index.html`.

No source app existed to copy from (from-scratch build, see root readme.md) — screens/copy are original proposals sized to the brief, not a recreation of an existing product.
