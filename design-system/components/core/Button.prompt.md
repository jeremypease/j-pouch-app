Standard call-to-action button — use `primary` for the one main action on a screen, `secondary`/`ghost` for lesser actions, `danger` for destructive actions (delete entry, etc).

```jsx
<Button variant="primary" icon="plus">Log output</Button>
```

Variants: `primary | secondary | ghost | danger`. Sizes: `sm | md | lg`. Supports `disabled` and an optional Lucide `icon` on either side.
