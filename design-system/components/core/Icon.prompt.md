Renders a single Lucide icon (via CDN), recolored with `currentColor`/a passed color using a CSS mask — use anywhere the design calls for a small line icon.

```jsx
<Icon name="droplet" size={18} color="var(--color-primary)" />
```

Icon names match lucide.dev exactly (kebab-case, e.g. `check-circle`, `alert-triangle`, `pill`, `activity`, `droplets`, `chevron-right`). Wrap in a flex container to align with text.
